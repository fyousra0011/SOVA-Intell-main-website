
  # File Alignment

  This is a code bundle for File Alignment.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

    Copy `.env.example` to `.env` and set `VITE_API_BASE_URL` to the backend URL. Vite variables are public; never put backend credentials or secrets in them.

    The backend lives in `../backend`. Run it separately with `npm install`, `npm run dev`, and configure `FRONTEND_URL=http://localhost:5173`.
